**RC-01 implemented and locally verified — 26 October 2026**

The accepted [recovery assessment](PORT_RECOVERY_2026-10-26.md) is lodged in Mote as `recovery-contracts`, its `recovery-rc01` / `recovery-rc02` / `recovery-rc03` children, `recovery-performance`, and `recovery-refit`. Existing GLMM/pathology/stress/live epics retain their scope. Gradient/performance promotion depends on the three correctness repairs; joint implementation depends on RC-01. The stale zerocorr epic description now recognizes its existing fitted support.

RC-01 preserves numerical termination as part of a fit. `LmmFit.optimizer` and `GlmmFit.optimizer` retain the TrustBQ result; `GlmmFit.pirls` records the final objective-change criterion, iteration count and finite halving-limit hits. The mutable PLS workspace does not own a reusable convergence certificate. Exhausted main optimizer budgets return `optimizer_budget_exhausted`; unfinished PIRLS returns `pirls_not_converged`; a nonfinite step remaining after halving returns `pirls_step_failed`. Underlying dimension and factorization errors remain typed errors. Public GLMM evaluation no longer converts failures to `Right(1e300)`.

`FitOptions.maxEvaluations` controls the main LMM search, excluding the advisory diagonal warm-start stage. `GlmmOptions` exposes `maxEvaluations` and `pirlsMaxIterations`. Existing defaults and fast-PIRLS tolerances are unchanged. Actual failed optimizer probes abort the fit; no penalty adapter or incomplete state rollback is used.

Raw θ assessment now reports `ThetaGeometry` with `fitStatus = NotAssessed`, clearing stale status even when the input certificate was previously assessed. Fit-backed assessment checks the retained optimizer result against the fit. `Compiler.assess(artifact, fit)` checks the artifact/formula/map match; `Compiler.assess(artifact, theta)` remains geometry-only. Compiled-design JSON is schema **2**, with `theta_geometry` separate from `fit_status`.

The existing `converged_*` status codes on fit-backed assessments mean an accepted numerical stopping criterion. They are not gradient/Hessian, conditional-score, or global-optimum certificates. Those stronger numerical claims are outside RC-01.

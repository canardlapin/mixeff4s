**RC-02 implemented and locally verified — 26 October 2026**

Mote `recovery-rc02` repairs the coefficient/covariance mismatch identified in the [recovery assessment](PORT_RECOVERY_2026-10-26.md). The original `reaction ~ 1 + zero + days + (1 | subj)` counterexample now returns two coefficients, two standard errors, and a 2×2 covariance matrix with the days coefficient correctly aligned.

`PlsWorkspace.vcov` returns its active covariance directly, in the same retained-column order as `beta` and `feNames`. It no longer expands to the original dimension with NaN rows. This also removes the unpivoting allocation; no performance claim was measured.

Both LMM and GLMM fits carry `fixedEffects: FixedEffectLayout`. It stores expanded requested column names and retained original indices; retained names and dropped indices/names are derived. `feNames` is derived from this layout. Indices are zero-based design-column positions, not formula terms. The retained estimates and covariance describe the selected reduced basis, not separate estimability of individual coefficients in the original redundant model.

The layout rejects repeated/out-of-range retained indices. LMM fits require beta and both covariance axes to match the retained rank; GLMM fits require beta length to match. Coefficient tables validate all vector lengths, including before Wald z construction. Direct construction and `copy` of inconsistent values throw `IllegalArgumentException`; recoverable fitting errors still return `FitResult`. The pre-release fit constructor parameter changes from `feNames` to `fixedEffects`; reading `fit.feNames` is preserved. README documents this boundary.

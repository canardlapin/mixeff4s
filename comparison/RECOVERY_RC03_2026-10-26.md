# RC-03: likelihood comparison contracts

Implemented locally on base `ec1937e2d2611c021519c4049c7eda49249f6311`, after RC-01 and RC-02, preserving the existing parity work. Mote issue: `recovery-rc03`.

## Result

`Lmm.fit` now captures immutable numerical design evidence: retained fixed columns, random basis columns, canonical grouping partitions, and full/diagonal covariance constraints. The snapshot is bound to response, criterion, theta, objective and parmap; comparisons reject missing or mismatched evidence and unsuccessful numerical termination. It retains O(n * (p + sum of random basis dimensions + number of grouping terms)) values; it does not retain a dense expanded random design or mutable fitting workspace. Memory and speed effects have not been benchmarked.

`Lrt.statistic(smaller, larger)` verifies structural nesting and returns the likelihood ratio plus a nominal parameter-count difference. `Lrt.compare` retains the existing result shape and supplies an asymptotic chi-square approximation only for fixed-effect ML changes with the same random covariance design. Covariance changes return `lrt_reference_unavailable`. The same refusal applies when either fit has a Cholesky diagonal <= 1e-8. Other unsupported/invalid comparisons return `lrt_unavailable`.

Nesting uses exact inclusion of actual retained columns, plus an injective match of random blocks with identical observation partitions and compatible covariance constraints. Matching preserves multiplicity and backtracks through augmenting paths. Random intercepts are included directly from the fitted basis. Renamed columns and relabeled grouping levels can match; same-named columns with different values cannot pass merely on their names. Full covariance cannot be embedded into a diagonal block. REML additionally requires identical retained fixed columns up to permutation, preserving likelihood normalization.

This is a sufficient, deliberately incomplete nesting certificate: scaled, centered or rotated equivalent bases may be refused. The accepted p-value remains an asymptotic approximation; the check does not certify covariance identifiability, small-sample adequacy, conditioning, global optimization or stationarity. The diagonal boundary screen is conservative, not a singular-value analysis.

## Scientific boundary

The former Pastes test asserted a conventional chi-square p-value while adding a variance component. That numerical reference is retained as a witness of the unchanged likelihood statistic, but is no longer exposed as a qualified p-value. The null lies on a variance boundary, where ordinary chi-square calibration cannot be assumed. See [Bates, likelihood-ratio tests on variance components](https://pages.stat.wisc.edu/~bates/IMPS2008/lme4-4a4.pdf) and [Self and Liang (1987)](https://doi.org/10.1080/01621459.1987.10478472). This implementation does not substitute a blanket 50:50 mixture or claim bootstrap calibration.
